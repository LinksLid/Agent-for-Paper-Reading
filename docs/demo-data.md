# 公开演示数据与口径

`examples/public-demo.json`来自2026-11-01团队保存的实际运行，是发布时整理的静态案例，不是下载后自动重新运行的结果。软件测试数也来自团队当时的检查，不表示访问者已在本机运行测试。

保留论文标题、官方来源、哈希/页码/片段ID、中文结论、核验记录、角色轨迹、数值指标、样本数量、源码提交和范围。

删去PDF全文、完整上下文、长引文、主机路径、执行命令长内容、认证、完整模型对话、原仓库快照和大型数据。公开引文最多80个字符并标注节选，不替代完整的原文支持检查。

`showcase/data/artifacts/*.json`是明确标注来源的评分摘要，不冒充完整原始文件。完整输出、pickle和包含全文的`state.json`不分发。

| 项目 | 口径 |
|---|---|
| 88接受/8排除 | 系统核验，不是人工事实正确率 |
| 4 ready/4 partial | 结构检查，不是论文整体正确性 |
| MAC-SQL 5/6 | 单数据库的小子集，不代表全量BIRD |
| 辩论3/10和10/10 | 原解析器与同一输出的额外格式审计，分别保留 |
| Self-Refine 2/2 | 首轮已正确、最终未变，不证明反馈收益 |
| ToT 0/2 | 低预算greedy1和旧评分器条件，不代表论文主配置 |
| 前提不足 | 无有效分数，不计作0 |

`auto`优先本机最新完成记录，无记录时回退公开案例；`demo`固定公开案例；`local`只读取本机。Pages工作流强制使用`demo`，不将个人运行导出为公共站点。
