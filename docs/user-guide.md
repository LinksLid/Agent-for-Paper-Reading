# 可视化阅读工作台使用手册

## 开始阅读

1. Windows 双击 `start.bat`；macOS/Linux 执行 `sh start.sh`。需要 Python 3.11+，首次自动安装依赖。
2. 浏览器自动打开 http://127.0.0.1:8600/#read 。右侧模型状态应为“已就绪”。未配置时填写自己的 Base URL、模型名称和 API Key 并保存。
3. 点击上传框或拖放 PDF，每篇不超过 20 MB、150 页，一次最多 3 篇。扫描件需先 OCR。
4. 在文本框提出问题，或选择“全面精读 / 重点看方法 / 重点看实验”。
5. 点击“开始阅读”，页面滚动到实时执行区域。

## 观察智能体执行

解析论文后，规划员制定关键词，方法分析和实验分析两个节点分别工作，再由核验员检查引用与结论。核验不通过时在上限内定向补查，随后生成详细讲解和报告。没有退回项时跳过修订。网页阅读默认不执行第三方仓库实验。

节点颜色与“执行中 / 已完成 / 未完成”来自实际 LangGraph 事件。API 调用和 token 统计在请求返回后更新，模型等待期间数字不一定变化。不会虚构百分比。图中两个分析节点并行，不表示同一服务的 HTTP 请求一定并发。

“阅读选项”可选单智能体、无语义核验的多智能体，适合做对照；详细讲解仅在核验模式生效。默认最多 60 次模型调用，可在 10—200 内调整。每次只运行一个任务。点“停止阅读”停止本机工作进程，已返回的请求仍会计入额度。

## 阅读和导出

### 选中不懂的地方提问

在已完成的真实阅读报告或“原文证据”中，选择同一段落内的2—1600字，点击浮动的“问一下”，右侧打开解释面板。也可用鼠标移到段落旁点击“问这一段”；键盘 Tab 可聚焦该按钮。先选中具体术语或句子，通常比整段提问更聚焦。

面板支持“通俗解释 / 举个例子 / 解释术语”及自定义问题。发送后显示原文检索、解释生成和证据核验状态；回答附可点击的原文PDF页码和引文。教学示例单独标为虚构推演、未实际运行，证据不足的回答内容会被隐藏。已有完整报告无需重跑即可提问；PDF阅读器内部划词和方法图节点提问尚未接入。

同一选文可继续追问，最多6次追问；每个问题最多8次模型调用，使用网页当前配置的同济兼容接口，调用量和token单独列在回答下方。提问会发送选文、相关论文片段及该问答链的历史到已配置接口。每份阅读同时回答一个问题，最多保存60条记录。

问答独立保存在本机 `.cache/web-jobs/<阅读任务ID>/questions/`，不会改写原阅读报告。刷新后点击报告标签旁“问答记录”恢复，选择历史问题可以继续追问或“回到选文”。报告版本变化会要求重新选择；切换论文任务时不会带入另一个任务的问答。服务重启导致中断的请求会标为未完成，可重新提问。

完成后，页面显示三个标签：

- **阅读报告**：中文内容、方法步骤、关键结果、局限和证据。引用编号可跳到报告末尾的来源。
- **原文证据**：逐条列出被接受的结论、引文和页码。点击页码在新标签打开这次上传的 PDF。
- **执行日志**：实际节点开始和结束时间，含返工后的重复核验。

“下载报告”保存 Markdown；“打印 / 保存 PDF”使用浏览器打印窗口。右侧“最近阅读”可重新打开旧报告；刷新网页也会恢复当前任务。任务在后台进程运行，离开该页面不停止阅读。

报告、状态和 SQLite 检查点位于 `output/web-任务编号/`，上传文件和网页任务元数据在 `.cache/web-jobs/`。这些目录与 `.env` 均不提交 GitHub，公开源码包不含个人论文、密钥和运行历史。

## 模型连接

网页“配置”保存到本机 `.env`，不会读回 Key；更新连接时 Key 留空表示保留。支持 OpenAI 兼容 Chat Completions，Base URL 应包含服务商要求的 `/v1`。没有 Key 仍可打开网站及公开历史案例，无法生成新报告。论文中的文本片段会发送给该服务。

## 启动与故障处理

PyCharm 打开项目并运行 `launch.py`。保持终端运行，Ctrl+C 停止；`python launch.py --port 8602` 更换端口。阅读不需要 Docker 或 GPU。原仓库复现属于可选高级入口：`python launch.py --workbench`，访问 8501。

| 情况 | 处理 |
|---|---|
| Python 版本过低 | 安装 3.11+，推荐 3.12 |
| 页面显示静态展示提示 | 运行 `start.bat` 后使用 8600 的网站，不是直接双击 HTML |
| 依赖未就绪 | 关闭旧服务再用启动器，或用项目虚拟环境 `pip install -r requirements.txt` |
| API 认证失败 | 在模型连接中更新自己的 Key |
| 配额或并发限制 | 等待恢复，降低任务频率，核对服务商套餐 |
| PDF 没有文字 | 先用 OCR 转为文本型 PDF |
| 超过大小或页数 | 压缩文件，或选择相关章节的 PDF |
| 刷新后没有报告 | 在最近阅读里选择任务；确认 output 和 .cache 未被移动 |
| 端口已被旧版占用 | 关闭旧服务后重启，或换端口 |
| GitHub Pages 上传不可用 | Pages 只托管静态文件；下载后运行本地后台 |

## 课程展示

先演示上传一篇 PDF 和实际进度，再展示报告与证据。可以在报告完成后录屏备用。项目总览、历史协作回放、证据筛选、复现实验和论文图书馆均可从导航栏进入。请区分这次上传的结果与随包的公开历史案例。
